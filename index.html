"I Read Code the Way You Read a Case File" — A 20-Year-Old Sleuth Talks Stacks, Signals, and Suspicious Bugs

By Rudra Prasad Pradhan, Lead Investigator · Filed from the Newsroom Floor

RUDRA PRASAD PRADHAN, photographed in his newsroom, hunting a particularly elusive CSS bug. — STAFF PHOTO

BERHAMPUR — In a profession crowded with frameworks and fads, one B.Tech student from NIST University is doing the unthinkable: writing code the old-fashioned way. With a magnifying glass over his keyboard, a notebook full of diagrams, and a long-standing feud with the autoplace feature in CSS Grid, Rudra Prasad Pradhan is fast becoming the programmer the rest of the industry calls when the case goes cold.

"Most people debug by guessing," the young investigator said in an interview with this paper, sipping a cold cup of tea. "I read code the way you read a case file — slowly, on purpose, and I always check the alibi of the last semicolon."

His current dossier includes a working Crop Recommendation System, four classifiers, a Flask backend, and a habit of writing things down before he writes them in code. "If you can't draw it on a whiteboard, you can't ship it."

CASE № 01 OPEN

The Crop Recommendation Mystery

A Flask + ML affair · Solved in part, upgraded in flight

An ML-powered web app that recommends the best crop to grow from soil and weather inputs. Uses an ensemble of four classifiers (Random Forest, SVM, XGBoost, and Gaussian Naive Bayes) and a majority-vote decision layer, served through a Flask backend. Generates classification reports and visual confusion matrices to compare model performance side-by-side.

Upgraded from manual entry to location-aware: pulls real-time temperature, humidity, and rainfall from a weather API using geolocation or a Pincode, with input clamping for safety.
